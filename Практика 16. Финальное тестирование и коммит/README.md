## Найденные ошибки и исправления

| Ошибка | Исправлено |
|---|---|
| логин ADMIN принят, хотя есть admin | проверка логина без учёта регистра (`ddc851f`) |
| пароль из пробелов принят | пароль из пробелов отклоняется (`ddc851f`) |
| пароль совпадает с логином | при проверке пароля передаётся пользователь (`ddc851f`) |
| почта длиннее 254 символов принята | `max_length=254` у поля (`ddc851f`) |
| оценка отзыва 0 и 100 принимается | поле оценки с границами 1 и 5 (`ddc851f`) |
| нет значка сайта, 404 в консоли | `favicon.svg` и ссылка в шапке (`9c48375`) |
| вошедший открывает регистрацию и вход | переход на главную (`9c48375`) |

Описание каждой ошибки со снимками «до» и «после» в репозитории `conference-qa`, папка «Задание 1». На каждую ошибку добавила тест в `tests.py` (класс `FixesAfterTestingTests`).
