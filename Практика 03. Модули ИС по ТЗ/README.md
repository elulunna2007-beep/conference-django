# Практика 3. Разработка модулей ИС в соответствии с ТЗ

Выполнила Терзи Эллия. Проект на Django, код в папке `portal`.

## Структура проекта

| Часть | Где лежит | Что в ней |
|---|---|---|
| Фронтенд | `portal/conference/templates`, `portal/conference/static` | шаблоны страниц и стили |
| Бэкенд | `portal/conference` (`views.py`, `forms.py`, `urls.py`) | классы представлений и формы |
| База данных | `portal/conference/models.py`, `portal/conference/migrations` | модели и миграции, SQLite |

Страницы показывает Django: адрес из `urls.py` вызывает класс из `views.py`, тот берёт данные из моделей и отдаёт шаблон.

## Модули

| Модуль | Что сделано |
|---|---|
| Регистрация (`RegisterForm`) | логин 3-20 символов, латиница, цифры и «_», уникальный; пароль от 8 символов (проверяют валидаторы Django); почта и телефон по формату, телефон приводится к виду +7XXXXXXXXXX |
| Авторизация | стандартный `LoginView` Django, выход кнопкой (POST) |
| Создание заявки (`ApplicationForm`, `ApplyView`) | помещение, способ оплаты и комментарий; нельзя подать заявку на прошедшее мероприятие и второй раз на то же |
| Просмотр заявок (`MyApplicationsView`) | участник видит только свои заявки со статусом |
| Панель администратора (`ManageView`) | все заявки в таблице, кнопка «Дальше» переводит заявку на следующий статус |

ООП: страницы это классы-наследники `ListView`, `CreateView`, `FormView`, формы это классы, у модели `Event` есть метод `is_finished()`.

## Как проверила

Запустила `python manage.py runserver 127.0.0.1:8101` и прошла все модули в Chrome. Чтобы показать ошибки сервера, у формы отключила проверку браузера (`noValidate`), иначе браузер ловит их раньше.

1. `01_registraciya_oshibki.png`: логин из 2 символов, плохая почта, телефон «12345», пароль из одних цифр. Ошибки под полями.
2. `02_login_zanyat.png`: логин `admin` уже занят.
3. `03_posle_registracii.png`: телефон «8 (900) 123-45-67» принят, пользователь вошёл.
4. `04_spisok_meropriyatij.png`, `05_forma_zayavki.png`, `06_moi_zayavki.png`: список, форма заявки и список моих заявок.
5. `07_panel_administratora.png` и `08_status_izmenen.png`: вход под администратором, статус заявки «новая» стал «назначено».

Помещение и способ оплаты пока обычные текстовые поля. Выпадающие списки сделаю в практике 9.
