# Конференции.РФ

Учебный портал для подачи заявок на участие в конференциях. МДК.09.01 «Проектирование и разработка веб-приложений», Терзи Эллия.

Python 3.12, Django, база SQLite, свой интерфейс администратора (`/manage/`) и стандартная админка Django (`/admin/`). Проект в папке `portal`.

## Запуск

```
python -m venv .venv
.venv\Scripts\activate
pip install -r portal/requirements.txt
cd portal
python manage.py migrate
python manage.py seed
python manage.py runserver
```
Сайт открывается на http://127.0.0.1:8000. Тесты: `python manage.py test`.
