# Практика 11. Разработка веб-приложения в соответствии с ТЗ

Выполнила Терзи Эллия. Код: `portal/conference`.

## Что сделано

| Пункт задания | Как сделано | Скриншот |
|---|---|---|
| Фронтенд с бэкендом | страницы Django берут данные из базы, формы отправляются на сервер и сохраняются в SQLite | все скриншоты |
| Добавление, чтение, обновление, удаление | мероприятия: администратор добавляет, смотрит список, изменяет и удаляет (`/manage/events/`), при удалении просит подтверждение; заявки: участник создаёт, читает и отменяет заявку, пока она новая | `01`-`05`, `11`, `12` |
| Смена статусов | метод `Application.advance()` переводит заявку только на следующий статус: новая, назначено, завершено; перескочить нельзя, на «завершено» кнопка пропадает | `06_status_novaya.png`, `07_status_naznacheno.png`, `08_status_zaversheno.png` |
| Отзывы после завершения | отзывы показаны на странице мероприятия со звёздами и средней оценкой, на карточке в списке тоже есть оценка | `09_otzyvy_na_stranice_meropriyatiya.png` |

Своя панель администратора (`/manage/`) устроена так: вкладка «Заявки» с фильтрами и вкладка «Мероприятия». Стандартная админка Django (`/admin/`) тоже подключена для всех моделей, названия сделала русскими (`10_standartnaya_adminka_django.png`).

Все действия администратора доступны только группе «Администраторы», участник на этих адресах получает 403 (проверено тестами). Форма мероприятия проверяет название (не короче 5 символов) и дату.

## Как проверила

Прошла весь сценарий в Chrome: добавила мероприятие, увидела ошибку короткого названия (`02`), удалила мероприятие с подтверждением (`04`, `05`), провела заявку по трём статусам, отменила новую заявку участника. Добавила 6 автотестов (всего 38, `python manage.py test`): создание, изменение и удаление мероприятия, запрет для участника, порядок статусов, отмена только новой заявки, средняя оценка.

## Результат

Приложение работает полностью: мероприятия и заявки создаются, меняются и удаляются, статусы идут по порядку, отзывы видны на странице мероприятия.
