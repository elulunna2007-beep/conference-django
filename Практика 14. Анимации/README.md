# Практика 14. Добавление анимации и микро-анимаций

Выполнила Терзи Эллия. Стили: блок «анимации» в конце `portal/conference/static/css/site.css`, JavaScript не понадобился.

## Что добавила

| Что | Как сделано |
|---|---|
| Переход между страницами | `@view-transition { navigation: auto; }` и стили `::view-transition-old/new(root)`: старая страница гаснет за 0,15 с, новая появляется за 0,25 с |
| Карточки | при загрузке мягко поднимаются снизу (`rise`, 0,45 с) с задержкой 60 мс на каждую следующую; при наведении поднимаются на 3 px, тень растёт, фото увеличивается на 4 % |
| Кнопки | при наведении тень, при нажатии кнопка уменьшается до 97 % |
| Поля форм | плавная смена цвета рамки и кольцо фокуса за 0,15 с |
| Главный экран | заголовок, текст и кнопки появляются по очереди |
| Сообщения | выезжают слева |

`01_navedenie_na_kartochku.png`: наведение на карточку и кнопку в Chrome.

## Как проверила, что анимации не мешают

- Кнопки и ссылки доступны сразу, анимация только меняет прозрачность и смещение, размеры блоков не меняются. Сдвиг макета (CLS) 0,001 и 0,002 с анимациями и без них.
- Если в системе включено «уменьшить анимацию», всё отключается блоком `prefers-reduced-motion`. Проверила эмуляцией этой настройки в Chrome: у карточки `animation-name = none`.
- Переход между страницами проверила событием `pagereveal`: после клика по «Мероприятия» браузер запустил view transition.

## Производительность

Скрипт `izmerenie.py` открывает страницу 7 раз в Chrome с анимациями и без них (в режиме «без» стили анимаций отключены) и берёт медиану. LCP это время показа самого большого элемента, кадры считаются за первую секунду после загрузки. Результат на скриншоте `02_zamer_i_proverki.png`:

| Страница | Режим | LCP, мс | CLS | Кадров за секунду |
|---|---|---|---|---|
| главная | без анимаций | 404 | 0,002 | 121 |
| главная | с анимациями | 416 | 0,002 | 121 |
| список мероприятий | без анимаций | 408 | 0,001 | 134 |
| список мероприятий | с анимациями | 480 | 0,001 | 135 |

С анимациями LCP на списке мероприятий больше примерно на 70 мс, потому что карточки появляются плавно, а не сразу. Это в пределах нормы (хороший LCP до 2,5 с). Частота кадров не изменилась, тяжёлых свойств (ширина, высота) не анимировала, только `opacity` и `transform`. Замеры делала на своём компьютере, на локальном сервере, у других машин цифры будут другие.

## Результат

Анимации добавлены, их можно отключить настройкой системы, производительность не просела.
