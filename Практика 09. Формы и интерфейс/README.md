# Практика 9. Улучшение форм и интерфейса

Выполнила Терзи Эллия. Код: `portal/conference` (`forms.py`, `views.py`, `models.py`, `templates`).

## Что сделано

| Пункт задания | Как сделано | Скриншот |
|---|---|---|
| Ошибки на странице | каждое поле выводит свои ошибки под собой (шаблон `_field.html`), поле с ошибкой получает красную рамку, общие ошибки формы идут в розовом блоке сверху | `01_oshibki_pod_polyami.png` |
| Выпадающие списки | «Помещение» и «Способ оплаты» теперь `select`: в модели `Application` у полей заданы `choices`, форма принимает только значения из списка (миграция `0004`) | `02_zayavka_vypadayushchie_spiski.png` |
| Фильтры и карточки в панели администратора | заявки показаны карточками, фильтр по статусу и по мероприятию через адрес (`/manage/?status=1&event=4`), кнопка «Сбросить», счётчик найденных заявок | `03_panel_kartochki.png`, `04_panel_filtr.png` |
| Отзыв только после завершения | метод `Application.can_review()`: заявка «завершено», мероприятие уже прошло, отзыва ещё нет; кнопка «Оставить отзыв» показывается только в этом случае, а прямой адрес `/applications/<номер>/review/` на сервере проверяет то же самое | `05_moi_zayavki_knopka_otzyva.png`, `06_otzyv_oshibka.png`, `07_otzyv_sohranen.png`, `08_otzyv_nelzya.png` |

К этому подключила дизайн из практики 7 ко всем страницам Django: `base.html`, карточки мероприятий, формы, статусы цветом. В списке мероприятий добавила фильтр по городу.

Форму отзыва проверяет сервер: оценка из списка 1-5, текст не короче 10 символов. Чужую заявку отзывом закрыть нельзя, будет 404.

## Как проверила

Прошла сценарии в Chrome: в 08 участница maria_v открыла адрес отзыва на заявку со статусом «назначено», её вернули на «Мои заявки» с пояснением. Дописала 7 автотестов Django (`python manage.py test`, теперь 32 теста, все проходят): отзыв до завершения, до даты мероприятия, чужая заявка, короткий текст, значения вне списка, фильтры панели.

## Что заметила по ходу

Когда вынесла карточку мероприятия в отдельный шаблон `_event_card.html`, главная упала с ошибкой `Invalid block tag: 'static'`: подключённый шаблон не видит `{% load static %}` из основного. Добавила строку в сам файл.

## Результат

Формы показывают ошибки на странице, списки вместо текстовых полей работают, панель администратора фильтрует заявки, отзыв доступен только после завершения.
